# Orbsie organization avatar

Generated with the built-in image generation tool on 2026-09-07 for the GitHub organization avatar. The original is `orbsie-org-avatar.png`; its source remains in the local generated-image library.

## Generation prompt

Use case: logo-brand. Create one exceptional orb-style brand mark for Orbsie, an imaginative conversational 3D world builder, specifically its GitHub ORGANIZATION AVATAR. Square 1024x1024 composition, designed to remain striking and recognizable at 40px and in a circular crop. A single bold luminous little planet/orb, with an elegant sweeping orbital ribbon forming a subtle open O silhouette, a sculptural jewel-like teal/cyan core and rich violet/indigo shadow, against a clean very dark midnight navy background. Polished graphic 3D icon, intentional iconic silhouette, confident limited shapes, crisp contour, restrained atmospheric glow, expressive sense of worlds coming alive. Orb and ribbon occupy about 78% of the square with safe margins. Sophisticated playful technology identity. No lettering, no wordmark, no text, no stars or tiny decorative clutter, no grids, no mockups, no borders, no watermark. Deliver a single finished avatar image.

## Upload status

Prepared for https://github.com/organizations/orbsie/settings/profile. Organization avatar upload requires an authenticated browser session; no controllable browser was available in this session. Committing the asset to the repository does not change the organization avatar.

## Favicon

`public/icon.svg` is a native SVG adaptation of Orbsie’s existing icon: the cyan orb, two lime land shapes and violet orbit remain clear at browser-tab sizes. It is wired through Next.js metadata, uses no external resources, and was visually checked at16,32,64 and160px (`docs/evidence/favicon-sizes.png`).

`orbsie-org-avatar-flat.png` is an intermediate built-in image edit that preserves the original identity while simplifying terrain texture. Both original and intermediate files are preserved. The organization avatar itself has not been changed.
