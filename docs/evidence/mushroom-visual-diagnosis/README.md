# Mushroom visual diagnosis

The authoritative catalog asset is
`public/models/kenney/nature-kit/mushroom_red.glb` (6,364 bytes,
SHA-256 `843e2de43dce78920a5675a67bac4b72f500e6220315e713fe08381642cfc571`).
The reproducible comparison is in
[`geometry-comparison.json`](geometry-comparison.json), generated by
[`mushroom-visual-diagnosis.test.ts`](../../../tests/mushroom-visual-diagnosis.test.ts).
The all-asset transformed-bounds audit is in
[`catalog-bounds-audit.json`](catalog-bounds-audit.json), generated by
[`catalog-source-bounds.test.ts`](../../../tests/catalog-source-bounds.test.ts).

The raw GLB has 48 triangles in two meshes: a 32-triangle `_defaultMat`
material region and a 16-triangle `colorRed` material region. The production
decoder outputs 144 non-indexed positions, preserves the raw node translation
and transformed bounds, retains both source material colors, and creates
matching formation attributes. The previous manifest incorrectly reported the
untranslated Y bounds; at scale 14 that is a 0.7-unit placement difference that
can hide part of the model. The corrected metadata is now checked by the
catalog verifier, using active indexed vertices rather than unused shared
accessor vertices.

The audit covered all 10 catalog GLBs and their active triangle counts:
114, 78, 48, 104, 80, 220, 186, 524, 264, and 200. Every asset had the
−0.05 Y node translation omitted from the previous metadata. The fence gate
also needed its transformed child extents corrected (Z max changed from 0 to
−0.43 and Y max from 0.3450273 to 0.2950273). Post-correction source-versus-
manifest deltas are below the verifier tolerance; the exact values are in the
audit JSON.

The settled route screenshot
[`desktop-route-failure.png`](../gateway-current-bounce-route-attempt-1/desktop-route-failure.png)
shows a low-poly silhouette consistent with the decoded mesh, but it was
captured before the metadata correction, so it cannot establish a source-shape-
only cause. Formation intentionally overwrites both `color` and
`formationColor` with the requested `#ff69b4` tint, removing material contrast.
Rerender after the metadata correction before selecting a visual fix. No new
browser comparison was run; the retained screenshot is the available visual
evidence.

Next action toward a recognizable mushroom: rerender the corrected placement,
then choose a clearer model or make preserving source material contrast an
explicit tint behavior decision. No app change is justified by this comparison
alone. Existing saved worlds may need visual/contact review where placement
relied on the old bounds; the GLB bytes and rendering transforms are unchanged.
