# Mushroom visual review

Root reviewed corrected front.png and rear.png against fixture source. All panels
use matching normalized geometry bounds, cameras and lighting. The corrected pink
panel replaces COLOR_0 uniformly with pink and uses white material, matching the
production tint operation. First-run evidence is retained separately because its
pink material multiplied original colors and was an incorrect comparator.

The baked GLB preserves the source silhouette and the main red/white regions, but
fine gills and white spots are visibly softened. Uniform pink still exposes a
separate cap, stem and skirt. The source itself has a very flat mature cap; this
is not sufficient evidence for the rounded giant mushroom sought in the flagship
workflow. No catalog admission or full visual-quality pass is claimed.
