Preserve current explicit credential-persistence choices.

ChatGPT subscription browser sign-in is documented through Codex App Server, but a hosted third-party subscription OAuth integration has not been established by the inspected documentation. The owner explicitly rejected installation: the entire user connection workflow must run in the browser. Local companions, desktop helpers and pasted private links do not satisfy this requirement. Do not silently substitute OpenRouter billing for the requested ChatGPT subscription, and do not count local account readiness alone as product connection acceptance.

Browser-only is a firm requirement. A supported hosted subscription integration remains unverified; retain that requirement as unresolved rather than replacing it with the existing companion experiment.

### Hosting candidate and integration boundary

[Vercel Sandbox persistence documentation](https://vercel.com/kb/guide/vercel-sandbox-duration-and-persistence) establishes resumable filesystem snapshots, not preservation of a running App Server process. An adapter must reinitialize RPC and verify account readiness on every resume. Default persistence would also retain authentication files; a login experiment should explicitly disable persistence until credential retention/deletion is implemented. [Pricing](https://vercel.com/docs/sandbox/pricing) meters provisioned memory even while idle, so runtime timeout and stop-on-disconnect are required; no Sandbox was provisioned during this investigation.

Proposed boundary: authenticated Orbsie routes use the existing `requireUser` and `checkOrigin` helpers, resolve an owner-bound runtime internally, and expose only login/status/cancel/logout and bounded scene generation. Never accept a browser-supplied sandbox ID or RPC method. Do not keep the authoritative owner-to-runtime mapping solely in a Next.js module variable. Process credentials and verification transactions belong to one owner session, with no developer-environment inheritance. Public readiness requires a separate account/model check after login. This is an architecture candidate, not deployed infrastructure or verified subscription access.
